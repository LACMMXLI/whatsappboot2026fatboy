Quiero que desarrolles únicamente el BACKEND de un sistema tipo SaaS para automatización de pedidos por WhatsApp enfocado en restaurantes.
Este backend será el núcleo del sistema y debe ser completamente funcional, escalable, modular y listo para producción.
NO generes frontend. Solo backend.
🎯 OBJETIVO DEL BACKEND
Este backend debe ser capaz de:

Guardar conversaciones tipo CRM
Crear y gestionar pedidos
Exponer APIs para frontend (CRM)
Integrarse con POS
Manejar menú dinámico y promociones

Framework: NestJS

ORM: Prisma
Redis: para eventos y colas
